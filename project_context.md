# Контекст проекта: Миграция интерфейса и переработка концепта игры

Этот документ создан для того, чтобы помочь разработчикам и ИИ-ассистентам в будущих сессиях быстро войти в курс дела и понять историю изменений проекта.

---

## 1. Общая суть изменений (Rework Overview)

В проекте была произведена **полная переработка концепта игры** и **миграция интерфейса планшета с устаревшей системы Unity UI (uGUI) на современную систему UI Toolkit**. 

Основные концептуальные изменения:
*   Удалена старая вкладка заказов товаров (`Shop/Cart`).
*   Интерфейс планшета (`TabletUI`) полностью переписан под UI Toolkit с премиальной версткой, гибкой сеткой и адаптивными стилями.
*   Боковая панель планшета оснащена качественными изометрическими ассетами-иконками с прозрачным фоном.
*   Добавлен конструктор напитков (`BrewCraft`) с гибкими слайдерами параметров (Сахар, Газ, Алкоголь), визуальным превью выбранного типа тары (Пластик, Банка, Стекло) и автоматическим расчётом цены партии.

## 2. Структура и ключевые компоненты планшета (UI Toolkit)

Основной класс управления планшетом — [TabletUI.cs](file:///c:/repositories/unity/Lemon-Empire/LemonEmpire/Assets/Scripts/UI/TabletUI.cs).

### Вкладки планшета (`_currentTab`):
*   **Индекс 0: Панель Управления (Home)**
    *   Отображает текущий день, время, баланс, дневную выручку/расходы/чистую прибыль и количество проданного товара.
    *   Кнопка завершения рабочей смены.
*   **Индекс 1: Склад и Запасы (Inventory/Warehouse)**
    *   Список доступных ингредиентов (лимоны, сахар, пустая тара и т.д.) с индикаторами запасов.
*   **Индекс 2: Конструктор Рецептов (BrewCraft)**
    *   *Поле названия*: ограничено 19 символами. Если пусто, выводит плейсхолдер `"НАЗВАНИЕ НАПИТКА"`.
    *   *Выбор тары*: три кнопки (Пластик, Банка, Стекло).
    *   *Слайдеры*: Сахар, Газ, Алкоголь (эмодзи удалены из названий). Ползунки (`unity-dragger`) и трекеры (`unity-tracker`) центрированы по вертикали через CSS-свойства `top: 50%` и `marginTop`.
    *   *Превью тары*: Отрисовывается динамически в методе `UpdateVisualPreview`.
    *   *Кнопка заказа*: позволяет заказать партию из 6 бутылок. Блокируется, если не хватает средств.
*   **Индекс 3: Улучшения Кафе (Upgrades)**
    *   Позволяет приобретать расширение зала, музыкальный автомат, торговый автомат, неоновые вывески и уличную мусорку.

## 3. Специфика рендеринга Превью Бутылок

Превью бутылок строятся полностью на элементах `VisualElement` в методе `UpdateVisualPreview`:

1.  **Банка (Can)**: Металлический серебряный цилиндр со скруглёнными углами (`borderWidth`, `borderColor`), верхним и нижним ободками и вертикальной полосой блика.
2.  **Пластик (Plastic)**: Прозрачная бутылка со скруглёнными плечами. Жидкость занимает 80% высоты. Имеется пластиковое кольцо горлышка и оранжевая крышка.
3.  **Стекло (Glass)**:
    *   **Горлышко (Neck)**: Короткое (высота `20f`), окрашено в белый цвет (`Color.white`) и не содержит жидкости, имитируя пустое горлышко бутылки.
    *   **Тело (Body)**: Широкая колба с сильно скругленными верхними плечиками (`borderTopLeftRadius = 40f`, `borderTopRightRadius = 40f`).
    *   **Жидкость (BodyLiquid)**: Заполняет только тело бутылки (уровень `80%`), создавая четкую границу налива под плечиками.

## 4. Стилизация и графические ресурсы

*   **Иконки меню**: Расположены в `Assets/Resources/UI/Icons/` (`IconHome.png`, `IconInventory.png`, `IconBrewCraft.png`, `IconUpgrades.png`). Они обработаны (удален белый фон, обрезаны пустые поля) и импортированы с флагом `alphaIsTransparency: 1`. В UI они занимают **76%** от площади кнопки боковой панели.
*   **Методы расширения стилей**: В связи с ограничениями версии Unity, свойства `borderWidth` и `borderColor` у `IStyle` не изменяются напрямую. Вместо этого используются методы расширения из вспомогательного класса [UIStyleExtensions.cs](file:///c:/repositories/unity/Lemon-Empire/LemonEmpire/Assets/Scripts/UI/UIStyleExtensions.cs) (например, `element.style.SetBorderWidth(width)`).

## 5. Важные уроки для следующих сессий (из lessons.md)

1.  **Интерфейс**: Ни в коем случае не возвращать старый uGUI интерфейс для планшета. Вся работа ведется в UI Toolkit.
2.  **Язык**: Использовать русский язык для написания планов реализации, обновлений задач и общения с пользователем.
3.  **Компиляция**: Всегда проверять работоспособность скриптов с помощью MCP-валидатора Unity (`validate_script`) и проверять консоль Unity (`read_console`) на наличие ошибок сборки.
